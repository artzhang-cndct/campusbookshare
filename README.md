# CampusBookshare

CampusBookshare is a web application designed to facilitate resource sharing among users. It allows users to create profiles, list resources, communicate via messages, and leave reviews and ratings for each other.

## **Features**
- User registration, login, and authentication.
- Resource listings with categories, descriptions, and availability.
- Messaging system for user communication.
- Reviews and ratings for users.
- Search functionality based on categories, keywords, and location.
- User dashboard to manage listings, messages, and reviews.
